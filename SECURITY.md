# Security Policy

## Supported versions

| Version | Supported |
|---|---|
| latest commit on `main` | yes |
| older | no |

## Reporting a vulnerability

Please do **not** open a public issue for a security problem.

Report it privately with GitHub's private vulnerability reporting: open the repository's **Security** tab and choose **Report a vulnerability** (https://github.com/KemalG-u/karincaai-algoritma-ornekleri/security/advisories/new).

Include: affected version, a description, steps to reproduce, and the impact you see. Never include real secrets or personal data in a report; describe where they appear instead.

## What to expect

This is a one-person project maintained on a best-effort basis. The maintainer aims to send an initial response within 14 days of a report. A fix date is not promised; the maintainer will tell you what is planned.

## Scope

In scope: the C# sample code in this repository (for example unsafe handling of crafted text or sample ranges). Out of scope: weaknesses of the .NET runtime or SDK, and misuse of the meaning gate for decisions it is documented not to support.
